  "content": "# PR 1973: refactor(playback): convert all response bodies to streams\nBranches: stream-all-response-bodies -> beta\n\nConsolidating all the possible response body objects into a stream has several advantages.\r\n- Reduces the code complexity before and after `respond` is called.\r\n- Reduces the code complexity around body delays.\r\n  The need for the `DelayedBody` class is eliminated and a simple timeout can be used before resuming the steam.\r\n- The `replied` event is emitted when the response body is provided as a stream.\r\n- Delaying content-encoded response bodies is now possible.\r\n- The timer on delayed bodies now starts after the `response` event listeners are processed.\r\n\r\nBREAKING CHANGES:\r\n\r\n- The third argument passed to reply header callbacks is now the original response body.\r\n  Previously, string bodies were passed to the callbacks as Buffers.\r\n- Interceptors are now marked as consumed _before_ the `request` event is emitted.\n\n##
